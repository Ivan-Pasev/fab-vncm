# Attribution and Rights Review

The independent research reference [Next-Concept Modeling](https://github.com/HazyResearch/ncm) is authored by its original researchers and distributed under its own MIT license. Its experimental findings and checkpoints are not inherited as FAB V-NCM results.

FAB V-NCM's original software remains **unlicensed for public source redistribution** pending an explicit rights and licensing decision. The private laboratory contains an archived v0.9.0 candidate under review. The public repository is documentation-only and does not contain a software implementation or an implied authorization to use private research data.

Before any public software source or derivative is introduced: review chain of title, third-party licenses and notices, confidential content, generated artifacts, permissions, provenance and security checks; then make a documented owner-controlled release decision. GitHub repository visibility is not a license grant.
