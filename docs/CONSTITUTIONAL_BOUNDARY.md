# FAB V-NCM — Constitutional Boundary (Pre-release)

## Product identity
FAB V-NCM is a model-neutral research-intelligence subsystem for source-bound concept extraction, hierarchical candidate refinement, independent bounded verification, and provenance-aware research review. It is **not** the HazyResearch NCM model, a CodexStation core replacement, or an independently validated theorem-discovery engine.

## Authority separation
1. Source observation does not imply authorial authority or consent.
2. A candidate is not an admitted claim; algebraic validity does not establish source relevance.
3. A valid signed artifact is not proof of model execution or correctness.
4. Local test success does not establish live host acceptance, neural inference, scientific discovery, or public release authorization.
5. Private research sources may not be projected into public distributions without a separate rights and confidentiality review.

## Canonical continuity
[Live Google Drive working tree](https://drive.google.com/drive/folders/1oeFz-wQnDJ_0rr76AdHLNxmgjsyAFns_) contains the research history, executable review candidate, release ledger and provenance. Private V-NCM code is under independent review. CodexStation retains its own parent authority and security gates.
