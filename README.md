# FAB V-NCM — Verified Concept Synthesis

**Status: constitutional product reference / pre-release.** This repository is the public-facing documentation root for the FAB V-NCM research programme. It is not yet an open-source software distribution and does not contain the experimental runtime.

## Scope

The programme investigates model-neutral research-concept graphs, immutable task and source contracts, scoped mathematical verification, independent evidence adjudication, and reviewable research briefs. Its reference runtime is developed separately in a controlled research laboratory.

**Verification limits:** A correct bounded polynomial proof is not an attestation of source authorship, scientific relevance, or empirical performance. Signatures do not establish genuine neural-model execution. The project does not claim authenticated pretrained NCM level-wise traces or independently demonstrated gains in scientific discovery.
